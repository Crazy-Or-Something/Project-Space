# Project Space

a lil space project on godot

## Current State

as 17/10/2026, lil tub (placeholder player) can move, look around, jump and run, basically the basic movement of mostly all games

![img](assets/README/status_image_17_10.png)

## Controls

### Movement

WASD = Move
Space = Jump
Left Shift = Run

### Sum misc

Left Alt = (Un)Lock Camera
